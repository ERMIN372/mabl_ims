## Временный плейсхолдер

TT Rationalist — **коммерческий слаб-сериф** TypeType. В бренд-PDF он зашит
только как *subset* (набор показанных глифов) — это не полноценный шрифт, и по
лицензии его нельзя извлекать из PDF и публиковать на сайте.

Пока лицензионных файлов нет, используется бесплатный слаб-сериф **Roboto Slab**
(самохостинг через `next/font`, с кириллицей) как временный плейсхолдер, близкий
по характеру. Реальный TT Rationalist стоит первым в шрифтовом стеке
(`src/app/globals.css`) и подключится автоматически, как только появятся файлы.

Шрифт можно приобрести/лицензировать у TypeType: https://typetype.org/
